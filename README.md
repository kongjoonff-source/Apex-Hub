# APEX HUB 홍보 사이트 (GitHub Pages)

디스코드 서버를 홍보하는 **원페이지 사이트**입니다.
스크롤을 내리면 소개 → 이미지 → 가격표 → 이용 가이드 → 공지 → FAQ 순서로 이어집니다.

---

## 1. 파일 구조

```
discord-pages/
├─ index.html              메인 페이지 (모든 섹션이 여기 한 페이지에 있음)
├─ admin.html              ★ 관리자 패널 (나만 사용 · 비밀번호 필요)
├─ terms.html              서버 이용약관
├─ privacy.html            개인정보 처리방침
├─ config.js               ★ 사이트 내용 (관리자 패널 또는 직접 수정)
├─ robots.txt              검색엔진에 관리자 패널 노출 방지
├─ assets/
│  ├─ css/style.css        디자인 (수정 안 해도 됨)
│  ├─ css/admin.css        관리자 패널 디자인
│  ├─ js/app.js            렌더링 스크립트 (수정 안 해도 됨)
│  ├─ js/admin.js          관리자 패널 로직
│  └─ images/              이미지 보관 폴더
│     ├─ logo.svg          로고 (교체 권장)
│     ├─ banner.svg        상단 배너 (교체 권장)
│     └─ shot-1~4.svg      갤러리 예시 이미지 (교체 권장)
├─ .nojekyll               GitHub Pages 필수 파일 (삭제하지 마세요)
├─ _check/                 자동 검사 스크립트 (올리지 않아도 됩니다)
└─ README.md               이 파일
```

> `_check/` 폴더는 사이트 동작을 자동으로 검사하는 개발용 파일입니다.
> GitHub 에 올릴 때는 **지워도 되고 그냥 올려도** 됩니다. (사이트에는 영향 없음)
>
> 검사 방법 (Node.js 필요) :
> ```
> node _check/verify.js       # 설정/파일 구조 검사
> node _check/test-index.js   # 메인 페이지 렌더 + 실시간 API 검사
> node _check/test-docs.js    # 약관 페이지 검사
> node _check/test-admin.js   # 관리자 패널 검사
> node _check/test-e2e.js     # 관리자 편집 → 사이트 반영 검사
> ```

## 2. ★ 관리자 패널 (상품 추가/삭제 · 나만 관리)

브라우저 주소 끝에 **`/admin.html`** 을 붙이면 관리자 패널이 열립니다.

```
https://내깃허브아이디.github.io/discord-pages/admin.html
```

**기본 비밀번호 : `apex-2026`**

> ⚠️ **꼭 바꾸세요!** 패널 왼쪽 아래 [🔑 비밀번호 변경] 에서 새 비밀번호를 입력하면
> 해시값이 나옵니다. 그 값을 `config.js` 의 `admin.passwordHash` 에 붙여넣으면 적용됩니다.

### 무엇을 할 수 있나요?

| 탭 | 할 수 있는 일 |
|---|---|
| 🏠 기본 정보 | 서버 이름, 소개글, **디스코드 초대 링크**, 로고/배너, 실시간 연동 설정 |
| 📊 통계 뱃지 | 멤버 수·접속자 수 등 숫자 카드 **추가/삭제**, 실시간 연동 on/off |
| 💰 가격표(상품) | **상품 추가 · 삭제 · 순서변경 · 복제**, 가격/혜택/배지/추천 설정 |
| ✨ 서버 자랑거리 | 특징 카드 편집 |
| 🖼️ 이미지 갤러리 | 이미지 추가/삭제 |
| 📖 이용 가이드 | 단계 추가/삭제, 순서 편집 |
| 📢 공지사항 | 공지 추가/삭제 |
| ❓ 자주 묻는 질문 | Q&A 추가/삭제 |
| 🔗 하단 정보 | 운영자, 문의, 푸터 링크 |
| 📜 🛡️ | 이용약관 · 개인정보처리방침 항목 편집 |

- 모든 목록은 **▲▼ 순서변경 · ⧉ 복제 · ✕ 삭제** 버튼으로 관리합니다.
- 편집하면 상단에 `● 저장되지 않은 변경사항` 표시가 뜹니다.
- **[사이트 미리보기]** 를 누르면 새 탭에서 실제 사이트를 확인할 수 있습니다.
- 탭을 닫으면 자동 로그아웃됩니다.

### 저장하는 방법 (2가지 중 편한 것)

**방법 1 — 파일로 내려받기 (토큰 불필요)**
1. [💾 저장하기] → [⬇ config.js 다운로드]
2. 내려받은 `config.js` 를 GitHub 저장소에 덮어쓰기 (Add file → Upload files → Commit)
3. 1~2분 뒤 사이트에 반영됩니다.

**방법 2 — GitHub에 원클릭 저장 (한 번만 설정하면 편함)**

> 🔒 **권장: Fine-grained 토큰** — 이 방식은 **해당 저장소 1개만** 접근할 수 있어 안전합니다.
> (classic 토큰의 `repo` 권한은 **내 모든 저장소**에 접근 가능하므로 위험합니다.)

1. GitHub → 오른쪽 위 프로필 → **Settings** → 왼쪽 맨 아래 **Developer settings**
2. **Personal access tokens** → **Fine-grained tokens** → **Generate new token**
3. 설정
   - **Repository access** → `Only select repositories` → 이 사이트 저장소만 선택
   - **Permissions** → `Repository permissions` → **Contents** 를 **Read and write** 로 변경
   - **Expiration** → 90일 등 짧게 설정 (만료되면 새로 발급)
4. **Generate token** → 토큰 복사 (`github_pat_...`)
5. 관리자 패널 [💾 저장하기] 에서 입력
   - GitHub 아이디 / 저장소 이름 / 브랜치(`main`) / 파일 경로(`config.js`) / 토큰
6. [🚀 GitHub에 저장] → 1~2분 뒤 사이트에 반영됩니다.

> 🔐 **토큰은 내 브라우저에만 저장**되며 `config.js` 나 저장소에는 **절대 올라가지 않습니다.**
> (코드로 직접 검증했습니다 — 아래 "보안 검증 결과" 참고)
> 공용 PC라면 [브라우저에 토큰 저장] **체크를 해제**하세요. 창을 닫으면 토큰이 자동 삭제됩니다.
> 사용 후에는 [토큰 삭제] 를 누르고, 토큰이 유출되면 GitHub 에서 즉시 **Revoke** 하세요.

### 🔐 "다른 사람이 보고 해킹당하는 건 아닌가요?" — 정직한 답변

**결론부터: 사이트를 통해 당신이 해킹당할 수는 없습니다.** 다만 아래 내용은 꼭 알아두세요.

**왜 안전한가요?**
- 이 사이트는 **서버·데이터베이스·회원가입·결제창이 전혀 없는 정적 페이지**입니다.
  저장되는 개인정보가 없고, 방문자가 뭔가를 "실행"시킬 수 있는 통로가 없습니다.
- 사이트에 들어있는 제3자 스크립트는 **폰트(CDN CSS) 하나뿐**이라 악성코드가 끼어들 여지가 거의 없습니다.
- GitHub 토큰은 **당신 브라우저의 저장소(localStorage)** 에만 있고, 사이트 파일에는 없습니다.
  방문자가 `config.js` 를 열어도 **토큰은 볼 수 없습니다.**

**그럼 `config.js` 가 공개되는 건 괜찮나요?**

| 공개되는 것 | 위험도 | 설명 |
|---|---|---|
| 상품·가격·가이드·공지 등 | ✅ 없음 | 어차피 방문자에게 보여주려고 만든 내용입니다 |
| 디스코드 초대 코드 | ✅ 없음 | 링크를 아는 사람은 누구나 들어올 수 있는 공개 정보입니다 |
| 관리자 **비밀번호 해시** | ⚠️ 주의 | 비밀번호 원본은 아니지만, **약한 비밀번호는 추측될 수 있습니다** |
| GitHub 아이디/저장소 이름 | ✅ 없음 | 저장소가 Public 이므로 이미 공개된 정보입니다 |
| **GitHub 토큰** | 🔒 비공개 | **저장되지 않습니다.** 절대 유출되지 않아요 |

**비밀번호가 뚫리면 무슨 일이 생기나요?**
1. 남이 자기 컴퓨터에서 관리자 패널 화면을 열 수 있게 됩니다. (이건 그냥 설정 화면일 뿐입니다)
2. 하지만 **저장을 하려면 GitHub 토큰이 필요한데 그건 당신 브라우저에만 있습니다.**
3. 즉 **실제 사이트를 바꾸거나 당신 계정을 건드릴 수는 없습니다.**

👉 따라서 **실질적인 피해는 사실상 없습니다.** 그래도 아래 3가지는 꼭 지켜주세요.

**꼭 지켜야 할 3가지**
1. **비밀번호를 반드시 바꾸세요.** 기본값 `apex-2026` 은 뚫릴 수 있습니다.
   → 길고 복잡하게 (`Apex!hub-9f3Kz#2026` 처럼). 기본값이면 패널에 **빨간 경고가 계속 뜹니다.**
2. **공용 PC에서는 토큰을 저장하지 마세요.** → [브라우저에 토큰 저장] 체크 해제
3. **토큰은 Fine-grained + Contents 권한만** 으로 발급하세요. → 최악의 경우에도 피해가 그 저장소 1개로 한정됩니다.

**더 강한 보안이 필요하다면**
- Cloudflare Access / Cloudflare Zero Trust 를 앞에 씌우면 관리자 페이지에 **이메일 인증**을 추가할 수 있습니다. (무료 플랜 가능)
- 관리자 패널을 아예 **GitHub 에 올리지 않고** 내 PC 에서만 열어서 쓰는 방법도 있습니다.
  (`admin.html` 만 로컬에 두고, 내용 수정 후 `config.js` 만 업로드)

### ✅ 보안 검증 결과 (자동 테스트로 확인함)

| 검사 항목 | 결과 |
|---|---|
| 토큰이 `config.js` 에 포함되는가 | ✅ **포함되지 않음** |
| 토큰이 사이트 파일에 저장되는가 | ✅ 저장 안 됨 (브라우저에만) |
| 비밀번호가 평문으로 저장되는가 | ✅ 해시(SHA-256)로만 저장 |
| [토큰 저장] 체크 해제 시 | ✅ 창을 닫으면 자동 삭제 |
| [토큰 삭제] 버튼 | ✅ 완전 제거 확인 |
| 기본 비밀번호 사용 중 경고 | ✅ 표시됨 |

## 3. 내용 수정하는 방법 (관리자 패널 없이 직접)

**오직 `config.js` 한 파일만 고치면 됩니다.** 메모장(VS Code 권장)으로 열어서
따옴표 안의 글자만 바꾸고 저장하면 끝입니다.

| 바꾸고 싶은 것 | config.js 에서 찾을 위치 | 관리자 패널 탭 |
|---|---|---|
| 서버 이름 / 한 줄 소개 / 소개글 | `server: { name, tagline, description }` | 🏠 기본 정보 |
| **디스코드 초대 링크 (구매 버튼 목적지)** | `server: { invite }` | 🏠 기본 정보 |
| 멤버 수 등 숫자 뱃지 (실시간 연동) | `stats: [ ... ]` (→ `live` 옵션) | 📊 통계 뱃지 |
| 실시간 갱신 주기 / 끄기 | `server: { liveStats }` | 🏠 기본 정보 |
| 서버 자랑거리 | `features: [ ... ]` | ✨ 서버 자랑거리 |
| **가격표 (상품 추가/삭제)** | `products: [ ... ]` | 💰 가격표(상품) |
| 가격표 아래 주의 문구 | `priceNote` | (직접 수정) |
| **이미지 목록** | `gallery: [ ... ]` | 🖼️ 이미지 갤러리 |
| **이용 가이드 (직접 작성)** | `guide: [ ... ]` | 📖 이용 가이드 |
| 공지사항 | `notices: [ ... ]` | 📢 공지사항 |
| 자주 묻는 질문 | `faq: [ ... ]` | ❓ 자주 묻는 질문 |
| 하단 운영자/문의/링크 | `footer: { ... }` | 🔗 하단 정보 |
| 이용약관 항목 | `terms: { items: [ ... ] }` | 📜 이용약관 |
| 개인정보 항목 | `privacy: { items: [ ... ] }` | 🛡️ 개인정보처리방침 |

### 예시 — 가격 바꾸기

```js
products: [
  {
    name: "베이직",
    price: "1,000원",          // ← 판매가
    originalPrice: "3,000원",  // ← 정가(취소선). 필요 없으면 이 줄 삭제
    badge: "가장 저렴",         // ← 카드 위 리본. 필요 없으면 이 줄 삭제
    desc: "설명 한 줄",
    items: ["혜택1", "혜택2"],  // ← 체크 목록
    buttonText: "구매하러 가기"
  },
  // ... 상품을 더 추가하려면 위 { ... } 를 쉼표로 이어서 붙이면 됩니다.
]
```

### 예시 — 가이드 직접 쓰기

```js
guide: [
  {
    title: "1단계 · 서버 입장",
    emoji: "🚪",
    steps: [
      "첫 번째 할 일",
      "두 번째 할 일"
    ],
    note: "주의사항 (없으면 이 줄 삭제)",
    video: "https://youtu.be/영상ID"   // (없으면 이 줄 삭제)
  }
]
```

> ⚠️ **주의**: 항목 끝에 쉼표(`,`)를 빠뜨리면 화면이 하얗게 나옵니다.
> 새 항목을 추가할 때 앞 항목 끝에 쉼표가 있는지 꼭 확인하세요.

## 4. 이미지 넣는 방법

1. 원하는 이미지 파일을 `assets/images/` 폴더에 넣습니다.
   - 파일명은 **영어 소문자 + 하이픈**을 권장합니다. 예) `shot-1.png`, `event.png`
   - 한글 파일명은 GitHub Pages에서 깨질 수 있습니다.
2. `config.js` 의 `gallery` 에 경로를 적습니다.

```js
gallery: [
  { src: "assets/images/내이미지.png", caption: "설명 문구" },
  { src: "assets/images/두번째.png",   caption: "설명 문구" }
]
```

3. 로고와 배너도 교체하려면:
```js
server: {
  logo:   "assets/images/logo.png",    // 로고 (정사각형 권장)
  banner: "assets/images/banner.png",  // 상단 배너 (가로로 긴 이미지 권장)
}
```

이미지 파일이 없으면 자동으로 숨겨지므로 사이트가 깨지지 않습니다.

## 5. GitHub Pages 에 올리는 방법

### 방법 A — 웹사이트에서 업로드 (초보자 추천)

1. [github.com](https://github.com) 로그인 → 오른쪽 위 `+` → **New repository**
2. Repository name 에 `discord-pages` 입력 → **Public** 선택 → **Create repository**
3. 생성된 저장소에서 **uploading an existing file** 클릭
4. 이 폴더(`discord-pages`) **안의 모든 파일과 폴더**를 드래그해서 업로드
   - ⚠️ 폴더째가 아니라 **안의 내용물**을 올려야 합니다.
     (`index.html` 이 저장소 최상단에 있어야 함)
   - `.nojekyll` 파일도 꼭 포함하세요. (숨김 파일이라 안 보이면 `Ctrl+H` 로 표시)
5. 아래로 내려 **Commit changes** 클릭
6. 저장소 상단 **Settings** → 왼쪽 메뉴 **Pages**
7. **Source** 를 `Deploy from a branch` 로, **Branch** 를 `main` / `(root)` 로 설정 → **Save**
8. 1~2분 뒤 아래 주소로 접속됩니다.

```
https://내깃허브아이디.github.io/discord-pages/
```

### 방법 B — Git 명령어로 올리기

```bash
cd "C:\Users\USER\Downloads\PylaAI-main (1)\discord-pages"
git init
git add .
git commit -m "APEX HUB 홍보 사이트"
git branch -M main
git remote add origin https://github.com/내깃허브아이디/discord-pages.git
git push -u origin main
```

그 다음 위 **6~8번**과 동일하게 Settings → Pages 를 설정하면 됩니다.

> 💡 주소를 `https://내아이디.github.io/` 로 짧게 쓰고 싶다면
> 저장소 이름을 `내아이디.github.io` 로 만들면 됩니다.

## 6. 자주 있는 문제

| 증상 | 원인 / 해결 |
|---|---|
| 화면이 하얗게 나옴 | `config.js` 에 쉼표(` , `) 누락 또는 따옴표 오류. 브라우저에서 `F12` → Console 확인 |
| 이미지가 안 보임 | 경로 오타 또는 대소문자 불일치. `assets/images/` 안에 파일이 있는지 확인 |
| 한글이 깨짐 | 파일 저장 시 인코딩을 **UTF-8** 로 저장 |
| 스타일이 안 먹음 | `assets/css/style.css` 경로 확인. 폴더 구조가 그대로인지 확인 |
| GitHub Pages 404 | `index.html` 이 저장소 **최상단**에 있는지 확인 |
| 약관 페이지에서 내용이 안 나옴 | `terms.html`, `privacy.html` 도 같이 업로드했는지 확인 |
| admin.html 이 안 열림 | 주소 끝이 `/admin.html` 인지 확인. 파일을 업로드했는지 확인 |
| 관리자 비밀번호를 잊음 | `config.js` 의 `admin.passwordHash` 를 지우고 패널에 들어가 새로 만들거나, 해시를 아는 비밀번호로 교체 |
| 관리자 저장(방법 2) 실패 | 토큰에 `repo` 권한이 있는지, 아이디/저장소/브랜치 이름이 맞는지 확인 |
| 실시간 멤버 수가 안 나옴 | 초대 링크가 **만료되지 않았는지** 확인 (디스코드에서 "만료 시간: 없음" 으로 재발급) |
| 관리자에서 저장했는데 사이트가 그대로 | GitHub Pages 반영에 1~2분 걸립니다. 브라우저 강력 새로고침(`Ctrl+F5`) |

## 7. 실시간 멤버 수 / 접속자 수 (자동 연동)

**이미 연동되어 있습니다.** 별도 설정 없이 동작합니다.

- 사이트에 접속하면 디스코드 공개 API에서 **실제 멤버 수 / 현재 접속자 수**를 가져옵니다.
- 1분마다 자동 갱신되며, 탭을 벗어나면 호출을 멈춥니다. (디스코드 과호출 방지)
- 숫자 카드 우측 상단에 초록색 **LIVE** 뱃지가 표시됩니다.
- 인터넷 문제 등으로 호출이 실패하면 **LIVE 뱃지가 흐려지고 `config.js` 에 적어둔 값이 그대로** 표시됩니다. (사이트가 깨지지 않음)

### 설정 방법 (`config.js`)

```js
server: {
  invite: "https://discord.gg/yJzXhMAETU",   // ← 이 주소에서 초대 코드를 자동 추출
  liveStats: {
    enabled: true,        // false 로 바꾸면 실시간 기능을 끔
    refreshMs: 60000      // 갱신 주기 (밀리초). 최소 30초로 자동 보정됨
  }
},

stats: [
  { value: "856", label: "서버 멤버",   live: "members" },  // ← 실제 멤버 수로 자동 갱신
  { value: "57",  label: "현재 접속자", live: "online"  },  // ← 실제 접속자 수로 자동 갱신
  { value: "24H", label: "자동 구매" },                     // ← live 가 없으면 고정값
  { value: "4.9/5", label: "고객 만족도" }
]
```

- `live: "members"` → 디스코드 실제 **멤버 수**
- `live: "online"` → 디스코드 실제 **접속자 수**
- `live` 를 지우면 `value` 에 적은 값이 그대로 고정 표시됩니다.

### ⚠️ 꼭 지켜야 할 것

| 항목 | 설명 |
|---|---|
| **초대 링크 만료 시간** | 디스코드에서 초대 링크 만들 때 **"만료 시간: 없음"** 으로 설정하세요. 링크가 만료되면 실시간 값이 안 나옵니다. |
| 값의 정확도 | 디스코드가 제공하는 **근사치**(approximate)입니다. 실제와 1~3명 정도 차이날 수 있습니다. |
| 서버 설정 | 디스코드 서버 설정에서 특별히 켤 것은 없습니다. (위젯 기능도 필요 없음) |
| 초대 코드 직접 지정 | 자동 추출이 안 되면 `liveStats.inviteCode: "yJzXhMAETU"` 처럼 직접 넣으세요. |

> 동작 원리 : `https://discord.com/api/v10/invites/초대코드?with_counts=true`
> 이 주소는 인증 없이 누구나 읽을 수 있는 디스코드 공개 API이며, 브라우저에서 직접 호출해도
> CORS 가 허용됩니다. (봇 토큰이 필요 없어서 안전합니다 — 토큰을 사이트에 넣으면 유출됩니다.)

## 8. 참고

- 폰트는 Pretendard(CDN)를 사용합니다. 오프라인에서는 기본 폰트로 표시됩니다.
- 초대 링크 복사 버튼은 `config.js` 의 `server.invite` 값을 복사합니다.
- 디스코드 실시간 위젯을 넣고 싶다면
  [디스코드 서버 설정 → 위젯 → 서버 위젯 활성화] 후 아래처럼 입력하세요.
  ```js
  server: {
    widget: "https://discord.com/widget?id=서버ID&theme=dark"
  }
  ```
